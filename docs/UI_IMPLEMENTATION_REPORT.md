# UI Implementation Report (18 Nov 2026)

Branch: `main` (local only, not pushed). Feature branches untouched at `06e10f2`.

## Screens (all on real host state)
Overview · Task · Context · Activity · Review (SafeChange Studio) · Models (ModelShield) · Proof, in the sidebar **and** in a new full-size editor tab ("AXIOM Forge: Open Workspace").

## Reusable components
`webview/src/ui/`: `primitives.tsx` (Dot, Figure, Meter, ViewHead, Section, Empty, Kbd, Skeleton, ViewBoundary), `icons.tsx` (7 original glyphs + 2 utility), `nav.tsx` (areas, NavContext).
`webview/src/components/`: Rail, Trace, Header, Composer, Timeline, Markdown, RecoveryBanner.
`webview/src/views/`: one file per area. `webview/src/derive.ts`: pure, tested derivations (runs, stations, durations, files touched, tool counts, test counts from real output, unverified changes, routing history, rail signals).
Removed: the old Review dock, Receipt ledger and Proof dock (replaced by full views).

- Two VS Code windows share one TrueForge MCP registration; the last to register wins.
- The relation map draws straight-across links behind middle-column labels; hover/focus highlighting keeps it readable.
- No live-model run has exercised the new screens yet.
- Context reasons still list matched words (engine output), not plain-language summaries.
- `Skeleton` exists but is unused.
