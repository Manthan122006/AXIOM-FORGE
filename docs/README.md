## Historical records

[historical/](historical/) holds the dated plans, status reports, audits and team packets written during development (17–19 Nov 2026). They are kept unchanged as a record. Their statuses and test counts describe the date they were written, not the current state; for that, see [VALIDATION.md](VALIDATION.md). `historical/screenshots/` contains browser-preview captures with **simulated** data from the UI work, not product screenshots.
